# bt_api_coinex

CoinEx exchange plugin for bt_api framework.

## Installation

```bash
pip install bt_api_coinex
```

## Usage

```python
from bt_api_coinex import CoinExExchangeDataSpot, CoinExRequestDataSpot
```

## Features

- REST API support
- HMAC-SHA256 authentication
- Symbol format: `BTC-USDT` -> `BTCUSDT`
